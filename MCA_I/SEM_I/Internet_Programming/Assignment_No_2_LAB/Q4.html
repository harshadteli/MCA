OSI Reference Model

  1. Application Layer
    • Provides services for user applications
    • Examples: Email, Web Browser, File Transfer
  2. Presentation Layer
    • Data translation, encryption, compression
    • Ensures data is in readable format
  3. Session Layer
    • Establishes, manages, and terminates sessions
    • Synchronization between applications
  4. Transport Layer
    • Reliable delivery of data (error checking, segmentation)
    • Protocols: TCP, UDP
  5. Network Layer
    • Logical addressing (IP addresses)
    • Routing of packets across networks
  6. Data Link Layer
    • Physical addressing (MAC addresses)
    • Error detection and correction on frames
  7. Physical Layer
    • Transmission of raw bits (0s & 1s)
    • Deals with cables, signals, and hardware
